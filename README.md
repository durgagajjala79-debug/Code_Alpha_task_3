CodeAlpha_Chatbot
A simple rule-based chatbot built for the CodeAlpha Python Programming Internship (Task 4).
How to Run
Bash
python3 chatbot.py

How it Works
Type messages like "hello", "how are you", "thanks", or "bye".
The bot matches your input against predefined keyword groups (greetings, wellbeing,
identity, thanks, help, farewells) and replies accordingly.
Unrecognized input gets a friendly fallback response.
Saying "bye", "goodbye", "exit", or "quit" ends the conversation.
Key Concepts Used
if-elif logic, functions, loops, input/output.
